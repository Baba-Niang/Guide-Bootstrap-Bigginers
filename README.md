# Guide Bootstrap – Débutants

## Présentation

Le **Guide Bootstrap – Débutants** est un guide pédagogique conçu pour accompagner les étudiants et les débutants dans l'apprentissage de **Bootstrap 5**.

L'objectif est de rendre les principaux concepts du framework accessibles grâce à des fiches de révision modernes, visuelles et progressives. Chaque notion est expliquée avec des exemples concrets afin de faciliter la compréhension et la mise en pratique.

---

## Objectifs

Ce projet a pour objectifs de permettre aux apprenants de :

- Comprendre les fondamentaux de Bootstrap.
- Construire rapidement des interfaces responsives.
- Découvrir les principaux composants du framework.
- Réviser efficacement grâce à des supports visuels.
- Mettre en pratique les notions à travers des exemples simples.

---

## Contenu du guide

Le guide couvre notamment les thèmes suivants :

- Introduction à Bootstrap
- Le système de grille (Grid System)
- Les conteneurs
- Les utilitaires d'espacement
- Les couleurs et la typographie
- Les tableaux
- Les images
- Les cartes (Cards)
- Les boutons
- Les formulaires
- Les barres de navigation (Navbar)
- Les composants interactifs
- Les fenêtres modales
- Les alertes
- Les composants de navigation
- Les icônes Bootstrap
- Les bonnes pratiques

---

## Technologies utilisées

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

---

## Méthode pédagogique

Chaque fiche est conçue selon une approche progressive :

1. Présentation du concept.
2. Explication de son utilité.
3. Illustration visuelle.
4. Exemple pratique.
5. Résultat obtenu.
6. Bonnes pratiques.

Cette organisation permet une compréhension rapide tout en facilitant la mémorisation.

Ouvrez ensuite le fichier `index.html` dans votre navigateur.
